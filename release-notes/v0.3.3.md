Developer ID 签名并已公证。**推荐下载 `OpenImg-v0.3.3.dmg`**，打开后把 OpenImg 拖进「应用程序」——
zip 那份是给应用内更新用的。已装 0.3.2 的可以直接在设置页里点「下载并安装」。

## 新增

- **应用内更新能装了**。此前只提示有新版，装还得自己下载替换；现在点「下载并安装」就地完成：带进度下载 → 校验 → 原子替换 → 停在「立即重开」等你点。装完不自动重启，你可能正传着图
- 装之前四道闸，少一道都不装：**摘要**与清单逐字节相符、解压后**顶层恰好一个 .app**、**签名**钉死团队号且已公证、**版本**必须严格高于本机且与清单一致（防的是拿签名完好的旧版把你降回去）
- 替换用 `RENAME_SWAP` 原子交换：要么整个换过去，要么原样不动，不存在「旧的没了、新的还没到」的那一瞬
- **发布多一张安装盘（.dmg）**，打开就是「拖进应用程序」。zip 解压后就地双击会触发 App Translocation，那种情况下自我更新永久失效

## 变更

- 装不了的话在**下载之前**就说清原因（不在「应用程序」里、已被 translocate），不让你白下 8 MB
- 更新那一行加了下载进度，装好后原地变成「立即重开」
