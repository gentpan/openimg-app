下载解压，拖进「应用程序」直接打开。Developer ID 签名并已公证，不需要右键打开，也不用去系统设置里放行。

需要 macOS 14 或更新版本，Apple Silicon。

## 界面

**换了新图标**，而且跟着主题走 —— 切到紫色主题，Dock 里的图标也变紫。（只换运行中的那张；Finder 和启动台里仍是绿版，`.app` 签过名，运行时改不了自己的资源。）

**品牌色更新**：绿换成 `#90FF3A`，紫换成 `#7624F4`。两套色阶都重算过，不是只换一格。

**侧边栏**换成一根会滑动的发光条，停在当前页那一行旁边。

**概览页与设置页重排**。原来是写死的两列，概览页左下空着一整片 523pt，窗口拉宽后左右各留白 236pt 没人用。现在按可用宽度求解，最宽排三列；默认窗口下的列宽和以前完全一样，卡片内部没有任何改动。

- 空间流水改成一页 5 条，翻页在标题右侧，即时切换不发请求
- 上传趋势的柱形图撑满卡片高度
- 最近上传的缩略图改成 4:3，悬浮浮出文件名（原来是 2:1 的扁条，竖构图的照片只剩中间一道）

## 账号

**可以直接在 app 里注册**，不用先去网站。

**Passkey 登录走系统原生弹窗**，不再打开浏览器。

**Google / GitHub 登录不再每次重输密码** —— 改为复用 Safari 的登录态，多数时候一闪而过。

**登录页去掉了「访问令牌」那一档**，账号密码和三个 OAuth 已经覆盖所有情况，包括自建服务器。

**昵称点一下才进编辑**，旁边出「保存」。原来是常驻输入框、失焦即存，点一下别处就把改动写进去了。

**修改密码 / 添加 Passkey 不再自动发验证码** —— 误点一次就烧掉一封受频率限制的邮件，现在发不发由你按。

**退出登录会请服务器作废令牌**，不只是本地清掉。

## 签到

**「一天」按你的本地时区算，不再是 UTC。** 原来东八区的日界落在早上 8 点 —— 7 点签一次、9 点还能再签一次，而凌晨签到会算成前一天。

## AI

**生成记录可以删除**，失败的和成功的都行。删除时可以选「只删记录」或「连图一起删」—— 记录里已经用掉的次数不会退回来。

**AI 水印只用 gpt-image-2**，透明底改本机抠，不再依赖上游。
