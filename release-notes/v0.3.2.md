## 修复

- **Passkey 在 App 内终于能用**。签名时漏了一条 `com.apple.application-identifier` 授权，平台凭证 API 一律拒绝——描述文件里一直授权着它，只是没签进去
- **登录后直接到概览**，不再先闪一下设置页
- **AI 余量「本月」不再自相矛盾**：那是余额（签到会加、生成会扣，可能超过配给），不是消耗进度
- **图库格子回到永远正方形**，余量上下对称居中

## 变更

- 顶栏省出一行：标题带图标，图库排序 tabs 收进中段
- 登录页指纹按钮按状态上色，没有 Passkey 时灰着并说清原因
- Passkey 失败时说出具体原因，不再静默回落网页
- 登录 / 注册切换移到表单上方；搜索框不再默认带光标
- 退出提示简化为「已退出」
